# SPECTRA — прототип исполняемой ленты

Кликабельный мок соцсети для креативных кодеров: каждый пост — живой
GLSL-шейдер, исполняемый прямо в ленте. Без бэкенда, все данные в памяти.

## Запуск

Из корня репозитория:

```bash
python3 -m http.server 8000
```

Открыть <http://localhost:8000/proto/>.

## Что внутри

| Экран | Маршрут | Что показывает |
|---|---|---|
| Лента | `#/` | карточки с механикой постер → live: шейдер играет только во вьюпорте, одновременно живых ≤ 4 (лимит WebGL-контекстов) |
| Артефакт | `#/a/:id` | большой live-канвас, код с подсветкой, дерево ремиксов с превью, чип «изменено N строк от родителя» |
| Редактор | `#/edit/:id` (`new` — с нуля) | сплит код/превью, live-перекомпиляция с ошибками компилятора, публикация ремикса в ленту и дерево |
| Джем | `#/jam` | мок войс-комнаты: хост «печатает» код в эфире, шейдер пересобирается на лету, спикеры/слушатели/рука, кнопка «Ремикс» утаскивает текущий снапшот в редактор |

## Архитектурные идеи, которые прототип демонстрирует

- **Видео не стримится.** В джеме синхронизируется только текст кода —
  канвас каждый зритель рендерит сам. Голос (в проде — LiveKit) здесь
  замокан UI-ом спикеров.
- **Постеры генерятся из кода** одним общим offscreen-раннером
  (`posterDataURL`), а не хранятся как картинки.
- **Ремикс — это `parent_id`**, дерево строится из плоского списка.

Прототип не трогает основной сайт — лежит целиком в `proto/`.
